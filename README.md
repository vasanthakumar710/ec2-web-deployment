# AWS EC2 Automatic Website Deployment

## Project Overview
Automatic deployment of a website using AWS services.

## Technologies Used
- GitHub
- AWS EC2
- AWS CodePipeline
- AWS CodeDeploy
- Apache Web Server
- Amazon Linux 2023
- HTML and CSS

## Deployment Process
1. Upload files to GitHub.
2. CodePipeline detects changes.
3. CodeDeploy deploys the files.
4. Apache hosts the website on EC2.

## Expected Output
Hello from AWS EC2!

This website is deployed automatically.

GitHub + CodePipeline + CodeDeploy
